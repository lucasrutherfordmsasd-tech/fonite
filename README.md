RELIC RUSH 100
==============
To play: open index.html in a desktop browser (Chrome, Edge or Firefox).
The game loads the Three.js 3D library from the internet the first time, so you need to be online.

To play fully offline:
1. Download three.min.js (version r128) from
   https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
2. Save it in this folder next to index.html.
3. In index.html, change the script tag's src from the cdnjs address to "three.min.js".

Controls
  Mouse       look / steer (full 360 degrees)
  WASD        move        Shift  sprint      SPACE  jump / open glider
  Click       shoot       Right-click  aim
  E open chest   R reload   1-3 or wheel: switch weapon
  Z bandage   X medkit   C small shield   V big shield
  Hold F      chop trees for wood
  Q           build mode (1 wall, 2 floor, 3 ramp, click to place, 10 wood each)
  [ and ]     mouse sensitivity   I  invert look

Goal: eliminate all 99 other players. Four bosses drop the best weapons.
